## 4. 测试策略

### 4.1 单元测试策略

A 组对既有核心服务和控制器测试进行完整回归，重点覆盖：

- 认证服务与认证控制器。
- 用户服务与用户控制器。
- 权限和参数校验中间件。
- 专业、课程等核心服务逻辑。
- 输入校验、异常路径、权限分支。

### 4.2 集成测试策略

本轮重点验证 A 子系统在 `develop` 集成版本上的后端集成测试是否全部通过，并关注以下链路：

- 注册、登录、修改密码、找回密码。
- 用户列表、详情、创建、状态更新、角色分配、删除。
- 部门 CRUD。
- 专业 CRUD。
- 课程查询与校验。
- 培养方案 CRUD。
- 角色权限管理。

### 4.3 系统测试策略

本轮手工系统测试按以下流程执行：

1. 使用 `admin` 登录，验证会话保持、菜单展示与 A 子系统主要页面。
2. 在用户管理、部门管理、专业管理、角色权限、课程信息、培养方案中执行查看、搜索、弹窗、编辑、删除等关键交互。
3. 使用 `teacher` 和 `student` 账号登录，验证不同角色下的访问表现与页面联调情况。
4. 对 B-F 子系统执行页面级冒烟，确认无白屏、无明显路由错误和登录态异常。

### 4.4 验收测试策略

本轮重点以以下标准判断是否达到当前阶段交付要求：

- A 子系统自动化测试必须通过。
- A 子系统前端关键页面必须可正常访问与操作。
- 登录、登出、刷新保持会话必须正常。
- 测试中发现的核心缺陷必须修复并完成回归。

### 4.5 回归测试策略

每次缺陷修复后重新执行原始复现步骤，并对相邻场景进行补充验证。本轮重点对部门编辑缺陷进行了回归确认，验证修复后：

- 原有可编辑部门不受影响。
- `description` 为空的部门记录可以正常编辑提交。

### 4.6 冒烟测试策略

本轮冒烟路径包括：

- 登录。
- 刷新后保持会话。
- 管理员查看基础信息管理菜单。
- 进入用户管理、部门管理、课程信息、培养方案。
- 教师与学生登录。
- 访问论坛、在线测试、成绩管理等页面入口。
- 登出。

### 9.3 主要缺陷分析

A 组本轮发现的主要缺陷属于前后端联调中的空值处理不一致问题：

- 后端部门更新接口允许 `description` 为字符串或不传。
- 前端编辑弹窗在部门原始数据 `description=null` 时，将 `null` 直接回填到表单并参与提交。
- 提交后被后端校验拦截，界面表现为点击“确定”后无明显反馈。

该问题属于接口数据约定与边界值处理不一致，不属于权限控制失效或核心业务规则错误。修复后已完成回归验证。

B 组缺陷主要集中在前后端契约、排课规则边界、权限控制和环境初始化：

1. BUG-B-001 属于环境初始化不稳定问题，依赖安装和 Prisma 生成顺序影响启动。修复后通过依赖卷复用和跳过重复安装回归验证。
2. BUG-B-002、BUG-B-003、BUG-B-005、BUG-B-006 属于前后端契约不一致，分别涉及教室设备字段、排课更新接口、导出格式和教室类型枚举。
3. BUG-B-004 属于冲突预校验稳定性问题，修复后通过教室时间冲突检测和冲突预校验回归。
4. BUG-B-007 属于高严重级别权限控制遗漏，写接口原先只做登录校验，修复后学生和教师调用写接口均返回 403，管理员请求可进入控制器。

C 组缺陷集中在准入租约并发写入边界：

- BUG-C-001 属于 Redis 租约状态在并发写入时的覆盖风险。修复后通过 TC-C-008、200 在线用户压测、双后端实例准入压测和 TTL 释放单测验证，未发现容量超卖或租约泄漏。

D 组缺陷主要集中在前端真实接口联调和异常提示体验：

1. BUG-D-001 属于跨模块数据来源问题。论坛模块原先依赖课程活跃统计接口或帖子列表反推课程，但学生账号没有统计接口权限，且课程暂无帖子时无法得到课程列表。修复后，论坛前端接入 C 组选课接口，学生端优先读取本人已选课程。
2. BUG-D-002 属于边界条件提示不足。附件上传失败时虽然接口会拒绝请求，但前端缺少持久可见的错误反馈。修复后，上传组件对格式、大小和接口错误统一生成提示，并在页面中保留错误 Alert。

E 组和 F 组本轮测试未保留未修复缺陷。

## 13. 测试结论

### 13.1 总体结论

基于本轮已执行测试，当前版本达到课程项目成果提交标准。

原因如下：

- A 子系统自动化回归与手工联调通过。
- B 子系统核心后端功能、权限控制、主要接口链路和排课结果写入链路通过。
- C 子系统自动化回归、前端组件测试、200 在线用户压测、AI live 人工样例、阶段管理和手动加课端到端验收通过。
- D 子系统论坛公告、发帖、附件、评论、检索、统计和权限控制通过。
- E 子系统题库、组卷、答题、自动评分、成绩查看和统计分析测试通过。
- F 子系统成绩录入、修改审批、查询分析、前端页面和收口链路测试通过。
- 登录、会话保持、菜单导航和主要页面联调正常。
- 本轮记录的 A/B/C/D 缺陷均已修复并回归通过，E/F 最新材料未保留未修复缺陷。
