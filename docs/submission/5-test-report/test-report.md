## 4. 测试策略【全组统一写】

### 4.1 单元测试策略

写作指引：
说明各组是否对核心服务、类、函数进行单元测试。重点关注输入、输出、边界条件和异常路径。

建议覆盖：

- A：权限校验、用户信息校验。
- B：冲突检测、排课结果生成。
- C：选课约束检查、容量控制。
- D：帖子发布、检索逻辑。
- E：自动评分、组卷规则。
- F：绩点计算、成绩修改状态流转。

### 4.2 集成测试策略

写作指引：
说明 A-F 之间如何联调。

重点集成链路：

- A → B：教师、课程信息用于排课。
- B → C：排课结果用于选课冲突判断。
- C → F：选课结果用于成绩录入对象。
- A → D/E/F：用户身份和课程信息用于论坛、测试、成绩。
- E → F：若在线测试成绩进入成绩管理，应测试该数据流。

### 4.3 系统测试策略

写作指引：
按完整用户业务流程测试。

建议流程：

1. 管理员创建用户和课程。
2. 教务维护教室并排课。
3. 学生制定培养方案并选课。
4. 教师在论坛发公告，学生发帖回帖。
5. 教师创建题库和试卷，学生在线答题。
6. 教师录入成绩，学生查询成绩和学分进展。

### 4.4 验收测试策略

写作指引：
用需求报告中的 Validation Criteria 验收。每条核心需求都应有对应测试用例。

### 4.5 回归测试策略

写作指引：
说明每次修复缺陷后如何重新执行相关用例，特别是权限、选课、排课、成绩这类容易产生连锁影响的模块。

### 4.6 冒烟测试策略

写作指引：
每次构建后先测试最核心路径，判断版本是否可进入详细测试。

建议冒烟路径：

- 登录。
- 查看菜单权限。
- 创建课程。
- 创建排课。
- 学生选课。
- 发帖。
- 在线答题。
- 查询成绩。

## 5. 测试用例设计【A-F 分组分别写】

### 5.1 测试用例模板

| 用例编号 | 所属子系统 | 对应需求 | 测试名称     | 前置条件   | 操作步骤 | 预期结果 | 实际结果 | 是否通过 | 缺陷编号 |
| -------- | ---------- | -------- | ------------ | ---------- | -------- | -------- | -------- | -------- | -------- |
| TC-A-001 | A          | FR-A-01  | 添加学生用户 | 教务已登录 |          |          |          |          |          |

写作指引：

- 用例编号按子系统区分。
- 每个核心功能至少一个正常用例和一个异常用例。
- 对关键功能补充边界用例。

### 5.2 A 基础信息管理测试用例【A 组填写】

建议覆盖：

- 添加学生/教师用户。
- 编辑用户信息。
- 删除用户。
- 搜索用户。
- 用户修改个人资料。
- 上传照片。
- 添加/编辑课程。
- 权限控制。
- 越权访问。
- 系统日志记录。

重点异常：

- 用户编号重复。
- 必填字段为空。
- 普通用户访问管理功能。
- 密码不符合规则。
- 上传非法文件类型。

### 5.3 B 自动排课测试用例【B 组填写】

建议覆盖：

- 添加/编辑/删除教室。
- 自动排课成功。
- 教师时间冲突检测。
- 教室时间冲突检测。
- 教室容量不足检测。
- 手动调课成功。
- 手动调课冲突提示。
- 教师课表查询。
- 教室课表打印。

重点异常：

- 无可用教室。
- 教师时间不可用。
- 课程容量超过所有教室容量。
- 手动调整到冲突时间段。

### 5.4 C 智能选课测试用例【C 组填写】

建议覆盖：

- 制定培养方案。
- 搜索课程。
- 查看课程详情。
- 正常选课。
- 正常退课。
- 选课结果查询。
- 教师导出学生名单。
- 教务控制初选/补退选时间。
- 教务手动加课。
- 在线用户连接数控制。
- 长时间停留用户强制退出。
- AI 辅助选课建议生成。

重点异常：

- 未制定培养方案直接选课。
- 课程容量已满。
- 时间冲突。
- 重复选课。
- 不在选课开放时间。
- AI 服务不可用时的提示或降级。

### 5.5 D 论坛交流测试用例【D 组填写】

建议覆盖：

- 教师发布公告。
- 用户发帖。
- 附件上传。
- 用户回帖。
- 留言交流。
- 发文数量统计。
- 热门帖子统计。
- 全文检索。

重点异常：

- 未登录用户发帖。
- 上传过大附件。
- 搜索无结果。
- 删除不存在帖子。
- 普通用户执行管理员操作。

### 5.6 E 在线测试测试用例【E 组填写】

建议覆盖：

- 添加选择题。
- 添加是非题。
- 查询/修改/删除题目。
- 手动组卷。
- 自动组卷。
- 学生开始答题。
- 测试计时。
- 中途退出无效。
- 提交试卷自动评分。
- 查看历史成绩。
- 教师查看统计图表。

重点异常：

- 题库为空时自动组卷。
- 重复提交试卷。
- 超时提交。
- 答案为空。
- 非课程教师管理题库。

### 5.7 F 成绩管理测试用例【F 组填写】

建议覆盖：

- 教师录入成绩。
- 教师查询成绩。
- 教师修改首次录入成绩。
- 二次修改成绩提交申请。
- 学生查询成绩。
- 学生查看学分进展。
- 课程平均分统计。
- 成绩分布统计。
- 排名统计。
- 个人绩点统计。

重点异常：

- 教师录入非本人课程成绩。
- 成绩超出合法范围。
- 学生查看他人成绩。
- 未经申请直接修改已发布成绩。
- 成绩分析数据为空。
